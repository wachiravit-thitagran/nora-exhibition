# AI NORA — สไลด์นิทรรศการ (static HTML)

ไฟล์เดียวจบ: `index.html` — เปิดวนลูปบนจอใหญ่ได้ทันที และอัดเป็นวิดีโอ 4K ได้

## 1. ติดตั้งให้อยู่ที่ `/nora-exhibition`

วางโฟลเดอร์นี้ใน web root ของ ainora.psu.ac.th ให้ได้โครงสร้าง

```
<web root>/nora-exhibition/index.html          สไลด์ 81 หน้า
<web root>/nora-exhibition/frame-picker.html   เครื่องมือเลือกเฟรมท่ารำจากวิดีโอ
<web root>/nora-exhibition/brand/              โลโก้ AI NORA + ฟอนต์ Anuphan
<web root>/nora-exhibition/assets/             ไฟล์สื่อ
```

**โลโก้ผู้สนับสนุน** — ทุกสไลด์มีโลโก้ AI NORA (มุมขวาบน) และแถบโลโก้
สำนักงานศิลปวัฒนธรรมร่วมสมัย · กระทรวงวัฒนธรรม · ม.สงขลานครินทร์ (แถบล่าง)
แทนการเขียนชื่อหน่วยงานเป็นตัวหนังสือ

สไลด์จะ**ดึงโลโก้จากเว็บต้นทางให้เองอยู่แล้ว** ถ้าไม่มีไฟล์ในเครื่อง จึงใช้งานได้ทันที
แต่ควรเก็บลงเครื่องด้วย เพื่อให้เปิดหน้างานได้แม้เน็ตหลุดและอัดวิดีโอ offline ได้ — รันครั้งเดียว:

```sh
sh brand/fetch-logos.sh
```

จะได้ `brand/logo-ocac.png`, `brand/logo-moc.png`, `brand/logo-psu.png`
(ถ้ามีไฟล์เวอร์ชันความละเอียดสูงกว่าอยู่แล้ว วางทับชื่อเดิมได้เลย)

**แบรนด์** — โลโก้ AI NORA (`brand/logo-dark.png` พื้นสว่าง / `brand/logo-light.png` พื้นแดง)
และฟอนต์ Anuphan variable (`brand/Anuphan-var.woff2`, น้ำหนัก 100–700, สัญญาอนุญาต SIL OFL
ดูที่ `brand/Anuphan-OFL.txt`) สีส้ม `#E88B00` ดูดมาจากโลโก้โดยตรง ใช้เป็นสีเน้นทั่วงาน
คู่กับแดงเลือดหมู `#7B1E28` และครีม `#FBF6EC` ตามธีม Nora Nakhon

แล้วเปิด `https://ainora.psu.ac.th/nora-exhibition/`

ถ้าเว็บเป็นแอป (Flask/FastAPI/Django) ไม่ได้เสิร์ฟไฟล์ static ตรง ๆ ให้เพิ่ม static route
ชี้ `/nora-exhibition` มาที่โฟลเดอร์นี้

**สำคัญ:** วิดีโอ 22 คลิปดึงจาก `/videos/{id}/file` แบบ root-relative — ทำงานได้เลย
เมื่ออยู่บนโดเมนเดียวกัน ถ้าจะเปิดจากเครื่องอื่นหรือเปิดแบบ offline ให้แก้บรรทัดเดียวใน
`index.html`:

```js
AINORA_BASE : 'https://ainora.psu.ac.th',
```

### 3.5 `assets/poses/` — ตัดเฟรมจากวิดีโอด้วย `frame-picker.html`

สไลด์หมวด "ภาพท่า + ภาพท่า = วิดีโอ" ใช้ภาพท่ารำที่ **ตัดมาจากตัววิดีโอเอง**
(66 เฟรม จาก 22 คลิป) เปิดเครื่องมือที่

```
https://ainora.psu.ac.th/nora-exhibition/frame-picker.html
```

> **ต้องเปิดจากโดเมน ainora.psu.ac.th** เท่านั้น เพราะเบราว์เซอร์ห้ามอ่านพิกเซล
> จากวิดีโอข้ามโดเมน (canvas tainted) เปิดจาก `file://` หรือโดเมนอื่นจะจับเฟรมไม่ได้

1. กด **จับเฟรมอัตโนมัติทั้งหมด** — ไล่เปิดวิดีโอทีละคลิป ตัดเฟรมตามจำนวนท่าในชื่อคลิป

2. เฟรมไหนไม่ตรงท่า เลื่อน slider หรือกด `−0.1` / `+0.1` วินาที (คลิกภาพแล้วใช้ลูกศร
   ← → ก็ได้ กด Shift ค้างเพื่อขยับละเอียด 0.02 วิ)
3. กด **ดาวน์โหลด poses.zip** แล้วแตกไฟล์ที่โฟลเดอร์โปรเจกต์ — ภาพจะลงที่
   `assets/poses/<videoId>-<ลำดับท่า>.jpg` ให้เอง แล้วรีเฟรช `index.html`
4. **บันทึก poses.json** เก็บเวลาที่เลือกไว้ กลับมาแก้ทีหลังได้ด้วยปุ่ม **โหลด poses.json**

ลำดับการหาไฟล์ของการ์ดท่ารำในสไลด์: เฟรมจากวิดีโอ (`assets/poses/`) →
ภาพซ่อมแซมจากหนังสือ (`assets/compare/` ตามตาราง `POSE_IMG`) → การ์ดชื่อท่า

แต่ถ้าจะอัดวิดีโอแบบ offline หรือกันเน็ตหลุดหน้างาน ให้กด **ดาวน์โหลดวิดีโอ 22 คลิป**
ใน `frame-picker.html` เอาไฟล์มาวางเป็น `assets/videos/<id>.mp4` แล้วตั้งใน `index.html`

```js

```

ถ้าไฟล์ในเครื่องหาไม่เจอ จะถอยไปใช้ URL บนเว็บให้เองอัตโนมัติ

## 4. เปิดใช้งานหน้านิทรรศการ

- `?kiosk=1` — ซ่อนปุ่มและคำใบ้ทั้งหมด **ใช้โหมดนี้ตอนอัดวิดีโอและตอนเปิดหน้างาน**
- `?slide=39` — เริ่มที่หน้าที่ระบุ (ใช้ตรวจงานทีละหมวด)
- คีย์: `Space` เล่น/หยุด · `←` `→` เปลี่ยนหน้า · `F` เต็มจอ · `R` กลับหน้าแรก
- เลื่อนเมาส์เพื่อเรียกแถบปุ่ม (หายเองใน 3 วินาที)
- เล่นจบหน้าสุดท้ายจะวนกลับหน้าแรกเองไม่มีที่สิ้นสุด

## 5. โหมดจอยาว 48:9 — จอ 3 จอเรียงกัน

เปิดด้วย `?ultra=1` (หรือกดปุ่ม `U` สลับสด ๆ ตอนจัดจอ)

เวทีขยายเป็น **11520×2160** แบ่งเป็น 3 ส่วน ส่วนละ 16:9 (3840×2160) พอดีจอละ 1 ส่วน

| จอ | บทบาท | แสดงอะไร |
|---|---|---|
| **ซ้าย** | เสริม | บันไดกระบวนการ 6 ขั้นตอน ไฮไลต์ขั้นที่กำลังแสดง · โลโก้ AI NORA · แถบโลโก้ผู้สนับสนุน — คนที่เดินผ่านรู้ทันทีว่ากำลังดูขั้นตอนไหนของโครงการ |
| **กลาง** | **หลัก** | สไลด์เนื้อหา เหมือนโหมดจอเดียวเป๊ะ ๆ ไม่มีอะไรเปลี่ยน |
| **ขวา** | เสริม | ป้ายกำกับนิทรรศการ — ชื่อท่า ลำดับท่า จำนวนภาพที่ใช้ ผลตรวจ ข้อควรรู้ ที่มาอ้างอิง และเลขหน้า สิ่งที่ยาวเกินกว่าจะลงจอหลักได้ |

พื้นหลัง ไล่สีทอง ภาพลายไทย และแถบ progress **พาดต่อเนื่องข้ามทั้ง 3 จอ** เป็นผืนเดียว

### ต่อจออย่างไร

**แบบที่ 1 — เครื่องเดียว จอ 3 จอ (แนะนำ)** ต่อจอทั้ง 3 เป็นเดสก์ท็อปเดียวเรียงแนวนอน
ให้ได้ความละเอียดรวม 11520×2160 แล้วเปิด

```
https://ainora.psu.ac.th/nora-exhibition/?ultra=1&kiosk=1
```

กด `F` เต็มจอ — ทุกอย่างซิงก์กันเองเพราะเป็นหน้าเดียว

**แบบที่ 2 — แยกเครื่องต่อจอละเครื่อง** เปิดเครื่องละ URL

```
จอซ้าย   ?ultra=1&panel=1&kiosk=1
จอกลาง  ?ultra=1&panel=2&kiosk=1
จอขวา   ?ultra=1&panel=3&kiosk=1
```

แต่ละเครื่องครอปเฉพาะส่วนของตัวเองเต็มจอ และสร้างแค่ pane ของจอนั้น (ไม่ถอดรหัสวิดีโอที่มองไม่เห็น)

**ทั้ง 3 เครื่องจะตรงกันเองโดยไม่ต้องเชื่อมต่อกัน** — โหมด `panel=` เปิด *โหมดซิงก์ตามนาฬิกา*
ให้อัตโนมัติ แต่ละเครื่องคำนวณจากสูตรเดียวกันว่า "เวลานี้ควรอยู่หน้าไหน วินาทีที่เท่าไรของหน้านั้น"
แล้วกระโดดไปตรงจุดนั้น รวมถึงเลื่อนวิดีโอไปวินาทีเดียวกันด้วย

- ใช้นาฬิกาเครื่อง (NTP) เป็นตัวอ้าง — macOS/Windows ปกติเพี้ยนกันไม่เกินหลักสิบมิลลิวินาที
- เปิดเครื่องใหม่กลางทาง จะกระโดดเข้าจังหวะที่ถูกต้องเองทันที ไม่ต้องกดอะไร
- ปุ่มเลื่อนหน้าถูกปิดในโหมดนี้ (เพราะนาฬิกาจะดึงกลับ) กด `Space` หยุดดูได้ พอเล่นต่อจะเข้าจังหวะเอง
- สั่งทับได้ด้วย `?sync=1` / `?sync=0`

> **ต้องมี `assets/durations.json`** เพื่อให้ไทม์ไลน์ของทุกเครื่องยาวเท่ากันเป๊ะ
> สร้างจาก `frame-picker.html` → ปุ่ม **อ่าน+บันทึก durations.json** (มีอยู่ใน `poses.zip` ให้ด้วยแล้ว)
> ถ้าไม่มีไฟล์นี้ ทุกหน้าที่มีวิดีโอจะใช้เวลาเท่ากันหมดตาม `SEC_VIDEO_DEF` — ยังตรงกันทุกจอ
> แต่คลิปยาวจะถูกตัด

### หน้าที่รวมเป็นผืนเดียวทั้ง 3 จอ

บางหน้าใช้พื้นที่ 48:9 เต็มผืนแทนการแบ่ง 3 ส่วน ตอนนี้ทำไว้แล้ว 7 หน้า

- **ปกใหญ่** — โลโก้และหัวเรื่องยักษ์พาดเต็มผนัง
- **ปกหมวดทั้ง 6** — เลขขั้นตอนสูง 900px ด้านซ้าย ชื่อขั้นกลาง และแถบ 6 ขั้นตอนเรียงยาวด้านล่างทั้งผนัง

หน้าพวกนี้ยังแสดงได้ปกติบนจอเดียว (16:9) เพราะเก็บเลย์เอาต์เดิมไว้คู่กัน

### จัดวางและตรวจงาน

- `?seam=1` ขึ้นเส้นทองคั่นรอยต่อจอ ใช้ดูว่าเนื้อหาตกขอบจอไหนไหม
- `?ultra=1&slide=39` ตรวจทีละหน้า
- เนื้อหาทุกจอเว้นขอบใน 150px จึงไม่โดนขอบจอ (bezel) กิน

## 6. อัดเป็นวิดีโอ 4K

สไลด์วาดบนเวที 3840×2160 จริง แล้วย่อให้พอดีจอ — ถ้าอัดที่ 4K จะได้ความคมเต็มพิกเซล

1. ตั้งความละเอียดจอ/หน้าต่างเป็น 3840×2160
2. เปิด `https://ainora.psu.ac.th/nora-exhibition/?kiosk=1` แล้วกด `F`
3. อัดหน้าจอที่ 3840×2160 (QuickTime / OBS) — ความยาวรวมประมาณ 8–10 นาที
   ขึ้นกับความยาววิดีโอแต่ละคลิป
4. กด `R` ก่อนเริ่มอัด เพื่อให้เริ่มจากหน้าแรกพอดี

> เสียงในวิดีโอถูกปิดไว้ (`muted`) เพราะเบราว์เซอร์บล็อกการเล่นอัตโนมัติที่มีเสียง
> ถ้าจะใส่เสียงประกอบ แนะนำใส่ตอนตัดต่อหลังอัด

## 7. ปรับแต่งที่ใช้บ่อย

แก้บล็อก `CONFIG` ที่ต้นไฟล์ `index.html`

```js
SEC_COMPARE   : 3,     // วินาที/หน้า หมวดเปรียบเทียบภาพ
SEC_VIDEO_MAX : 20,    // เพดานเวลาหน้าที่มีวิดีโอ
SEC_VIDEO_DEF : 8,     // เวลาสำรองถ้าอ่านความยาววิดีโอไม่ได้
SHOW_DIVIDERS : true,  // ปกหมวด
ULTRA         : false, // true = เปิดโหมดจอยาว 48:9 เป็นค่าเริ่มต้น
ANIMATE       : true   // false = ปิดอนิเมชันทั้งหมด
```

ตาราง `POSE_IMG` คือการจับคู่ "ชื่อท่าในชื่อวิดีโอ → ไฟล์ภาพท่า" อ้างจาก
`README-การจับคู่.md` ใน Drive (ยึดท่าทางในภาพ ไม่ยึดชื่อไฟล์) ใช้เป็น **ตัวสำรอง**
เมื่อยังไม่มีเฟรมใน `assets/poses/` — ยังไม่ได้จับคู่ 3 ชื่อ:
**ท่าเทวดา, ท่าพนมมือ, ท่าจีบปรกหน้า**
ถ้าใช้ `frame-picker.html` ตัดเฟรมครบแล้ว ทั้ง 3 ชื่อนี้ก็จะมีภาพเอง ไม่ต้องจับคู่
